# Filament Dashboard Widgets

A curated collection of reusable dashboard widgets for FilamentPHP, extracted, refactored, and generalized from real-world enterprise applications.

## Features

- Clean and reusable architecture
- Easy to integrate into existing Filament panels
- Production-inspired implementations
- Well documented
- Open-source and MIT licensed

## Included Widgets

- Active Projects Chart
- Statistics Overview
- Alert Statistics
- Projects Status Chart
- Latest Projects Table

## Requirements

- PHP 8.2+
- Laravel 11+
- FilamentPHP 3+

## Roadmap

- More chart widgets
- More statistics widgets
- Table widgets
- KPI widgets
- Installation as a Composer package
